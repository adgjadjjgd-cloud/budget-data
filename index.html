2. Créez un fichier data.json dans ce repo avec le contenu {}
3. Sur GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
4. Générez un token avec la permission repo cochée
5. Renseignez vos informations ci-dessous et cliquez Sauvegarder
